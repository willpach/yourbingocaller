    Saved Sets

    Create / Edit Custom Vocabulary Set

    This list saves automatically — no extra step needed. Use number | word to show a big number with the word underneath, or column | number | word for full B‑I‑N‑G‑O style cards with column headers and a live tracking board. If the written word and the spoken word differ (like kanji vs. its reading), add a 4th part: column | number | word | spoken (or number | word | spoken without a column). The last part is always what's spoken aloud and matched to audio files.

    Loads a plain text or spreadsheet-exported CSV file straight into the box above (added to whatever's already there). Need a starting point? download a spreadsheet template.

    Audio for each term (optional)

    By default every term is read aloud with your computer's built-in voice. To use real recordings instead (e.g. a native speaker), either drop a batch of audio files below and they'll be matched automatically by filename, or attach one manually per term in the list.

    Example: a file named uno.mp3 automatically attaches to the term "uno".

    Pattern Library

    Patterns only apply to 5-column "structured" sets (every term has a column letter and a number) — the built-in 75-ball set, or a custom set typed like B | 1 | word. Selecting a pattern in the Caller tab skips calling any column it doesn't need.

    Design a Pattern

    Click cells to mark them required. The center is always FREE. For a regulated or paid game, match your official pattern sheet exactly — that's more reliable than a transcribed guess.

    Game Progression

    Build an ordered sequence of games to play on the same cards without resetting the called numbers — e.g. Regular Bingo, then Letter "X", then Blackout. "Next Game" in the Caller tab advances through this list; already-called numbers stay marked, and any column the new game needs that was previously skipped comes back into play.
