# Bingo Caller

A self-contained browser bingo caller. Open `index.html` in any modern browser; no install or server needed.

## Features
- **Caller:** draw, auto-play, undo, repeat and reset, with voice call-outs and a board of called numbers
- **Cards:** generate and print unique bingo cards
- **Vocabulary Sets:** custom term lists (e.g. language-learning bingo) with optional recorded audio, plus JSON import and export
- **Patterns:** a library of winning patterns, a pattern designer and multi-game progressions
